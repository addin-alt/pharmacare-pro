## ✨ Project Overview

**PharmaCare Pro** is a modern, responsive, web-based pharmacy management system built with **C#**, **ASP.NET Core**, **Blazor**, **Entity Framework Core**, and **Supabase PostgreSQL**.

The system is designed to help pharmacies manage medicines, inventory batches, expiry dates, purchases, sales, prescriptions, suppliers, customers, expenses, employees, payments, and business reports from one secure platform.

PharmaCare Pro is intended for:

* Retail pharmacies
* Medicine shops
* Community pharmacies
* Multi-branch pharmacy businesses
* Pharmacy owners and managers
* Pharmacists
* Inventory officers
* Sales employees
* Accountants

The primary objective is to create professional pharmacy software that can be configured and deployed for real pharmacy operations after development, testing, security review, legal review, and pharmacy acceptance testing are complete.

---

## 🎯 Primary Objectives

* Replace manual pharmacy records with a centralized digital system
* Track medicines by batch number and expiry date
* Reduce expired and out-of-stock medicine problems
* Speed up barcode-based sales and billing
* Maintain prescription and patient records
* Track supplier and customer payments
* Calculate sales, purchases, expenses, and profit
* Support single-branch and multi-branch pharmacies
* Provide secure employee access based on roles
* Generate accurate pharmacy reports
* Create a responsive interface for desktop, tablet, and mobile devices
* Make pharmacy setup and deployment straightforward

## 🧠 How It Works

```text
Step 1: Configure the Pharmacy

The pharmacy owner enters the pharmacy name, logo, address,
contact details, license information, tax settings, branches,
invoice settings, and stock alert preferences.

Step 2: Add Medicines and Suppliers

Employees add medicine information, manufacturers, generic names,
categories, suppliers, barcodes, prices, and reorder levels.

Step 3: Record Purchases

Purchase invoices are entered into the system. Medicine batches,
expiry dates, quantities, purchase prices, and supplier balances
are created automatically.

Step 4: Sell Medicines

Employees scan a barcode or search for a medicine. The system
selects the appropriate batch, calculates discounts and taxes,
records payment, and generates a printable invoice.

Step 5: Track Inventory

Every purchase, sale, return, transfer, adjustment, damage,
expiry, and disposal creates a stock movement record.

Step 6: Monitor Pharmacy Health

The dashboard displays sales, purchases, profit, low stock,
expired medicines, upcoming expiry dates, and outstanding balances.

Step 7: Generate Reports

The pharmacy owner or authorized employees can generate sales,
purchase, stock, expiry, profit, tax, customer, supplier, and
audit reports.
```

## 🔑 Supabase Configuration

PharmaCare Pro will use Supabase PostgreSQL as its cloud database.

Required configuration may include:

```env
ConnectionStrings__DefaultConnection=YOUR_POSTGRES_CONNECTION_STRING
Supabase__Url=YOUR_SUPABASE_PROJECT_URL
Supabase__AnonKey=YOUR_SUPABASE_ANON_KEY
Supabase__ServiceRoleKey=YOUR_SUPABASE_SERVICE_ROLE_KEY
```

These values are placeholders.

Real secrets must be stored using:

* .NET User Secrets during local development
* Secure environment variables during deployment
* A trusted secret-management service in production

Never save real passwords or API keys inside files that will be uploaded to GitHub.

---

## 🔒 Configure Local Secrets

Initialize .NET User Secrets:

```bash
dotnet user-secrets init --project src/PharmaCarePro.Web
```

Add the database connection:

```bash
dotnet user-secrets set \
"ConnectionStrings:DefaultConnection" \
"YOUR_SUPABASE_POSTGRES_CONNECTION_STRING" \
--project src/PharmaCarePro.Web
```

Add the Supabase URL:

```bash
dotnet user-secrets set \
"Supabase:Url" \
"YOUR_SUPABASE_PROJECT_URL" \
--project src/PharmaCarePro.Web
```

Add the Supabase anonymous key:

```bash
dotnet user-secrets set \
"Supabase:AnonKey" \
"YOUR_SUPABASE_ANON_KEY" \
--project src/PharmaCarePro.Web
```
